# 示例

以下示例用于展示输出节奏。示例重点是“如何组织研究库”，不是替你完成真实品牌授权。

## 示例 1：单品牌研究卡

用户请求：

```text
用 $brand-visual-research-builder 帮我研究 Apple 的官网视觉，后面我要做一组耳机主视觉，不要保存原图，只要链接和规则。
```

输出模式：

```text
研究任务：
- 品牌 / 产品线：Apple / 消费电子产品主视觉
- 研究目标：为耳机主视觉建立官网启发方向
- 证据状态：直接读取官方页面

来源台账：
- 页面类型：官网首页 / 产品页 / Newsroom
  链接：https://www.apple.com/airpods-pro/
  读取理由：确认材质、近景光线和留白控制
  视觉证据：产品居中、背景干净、边缘高光克制

核心观察：
- 品牌视觉领域：精密极简、留白高控制、表面完整
- 构图与景别：中近景 hero，多数画面保留文字安全区
- 光线与色温：柔和主光 + 边缘高光，避免复杂环境彩光

Prompt Translation Rules：
- 镜头：中近景平视 hero
- 光线：柔和主光，轮廓高光清楚
- 材质：玻璃与金属边界干净
- 文案 / logo 处理：画面预留空白，不做可读文字

Failure Risks：
- 像普通白底电商图
- 加太多科技炫光
- 机身文字乱码
```

## 示例 2：多品牌对比

用户请求：

```text
我在 Apple 和 Dyson 之间选产品发布会视觉方向。先做官网研究对比，不要直接写 prompt。
```

输出模式：

```text
对比结论：
- Apple：
  核心视觉领域：精密极简、克制留白、表面光洁
  Prompt Translation Rules：产品居中、边缘高光、背景控制干净
  Failure Risks：跑成普通电商白底、过度赛博、假文字
- Dyson：
  核心视觉领域：工程感、功能展示、结构解释
  Prompt Translation Rules：结构清晰、功能件颜色明确、实验室级灯光
  Failure Risks：像普通家电、结构逻辑乱、特效过多

最关键差异：
- 光线：Apple 更柔和克制，Dyson 更偏工业展示
- 材质：Apple 偏整洁表面，Dyson 强调功能材料分层
- 是否适合混用：只适合混“精密感”，不适合混完整世界观
```

## 示例 3：研究转 Prompt Brief

用户请求：

```text
我已经研究完 Nike 跑步页了。帮我把研究结论转成一个给 prompt director 的 brief，不要出现官方授权表述。
```

输出模式：

```text
研究转译 Brief：
- Style anchor：真实触地的性能跑步视觉，速度感来自身体与地面的关系
- Camera：低机位、局部裁切、运动瞬间
- Light：方向性训练场光或雨后反射光
- Material：网布、橡胶、汗感、潮湿路面
- Color：中性基底 + 高对比点缀色
- Space：跑道、清晨街跑、训练场边缘
- Text / logo policy：保留干净区域，后期补字
- Negative constraints：不要赛博烟雾、不要悬浮鞋、不要可读 slogan
```

## 示例 4：只做风险复核

用户请求：

```text
我已经做了一个 Porsche 风格的车图方向。你不要帮我改 prompt，只看这个研究方向里哪些地方不能照抄官网公开物料。
```

输出模式：

```text
风险复核：
- 不能直接照抄：特定广告构图、受保护标志、可识别官方版式、精确徽标细节
- 可安全保留：低机位轮廓逻辑、道路接地关系、黄昏斜光、克制反射
- 最可能的翻车点：假徽标、过度 motion blur、车身比例失真
- 更安全的研究措辞：受 Porsche 官方公开页面启发的性能视觉方向
```

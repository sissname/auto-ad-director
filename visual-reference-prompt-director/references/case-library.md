# Case Library

Use these text-only cases as v1 reference patterns. They are not stored source images and should not be treated as official brand or campaign material.

## Case 1: Rainy Automotive Night Reference to Running Shoes

Input type: described car-ad reference.  
Reference observation: low-angle night frame, wet black asphalt, blue rim light from rear side, long reflection under a glossy vehicle, upper-frame darkness for typography.  
User goal: keep the mood and reflection logic, change subject to running shoes.

Transfer:

- Keep wet ground, low camera, long reflection, hard blue rim light, dark negative space.
- Change vehicle geometry into shoe-specific outsole, mesh, and pair alignment.
- Avoid copying car brand, vehicle silhouette, license plate, campaign layout, or exact typography area.

Prompt logic:

- Subject must be physically grounded on wet asphalt.
- Reflection must align below shoes, not create duplicate shoes.
- Negative constraints must mention fake logos, warped soles, random text, excessive neon, and broken reflections.

## Case 2: Low-Key Fashion Portrait to Perfume Still Life

Input type: described black-and-white fashion portrait.  
Reference observation: one side-lit face, shadow-dominant vertical composition, shallow focus, soft filmic grain, very few props.  
User goal: translate the mood into a perfume bottle hero image.

Transfer:

- Keep low-key side light, shadow field, narrow highlight, restrained monochrome palette, shallow depth.
- Change human face into bottle silhouette and glass/liquid highlight behavior.
- Avoid copying model likeness, pose, clothing, hair, makeup, exact crop, or editorial identity.

Prompt logic:

- Bottle should have controlled glass edges and readable silhouette.
- Surface contact and reflection should be simple.
- Negative constraints must mention fake label text, warped bottle geometry, noisy glass, and copied portrait likeness.

## Case 4: Mall Light Tunnel to Skincare Pop-Up

Input type: described spatial installation reference.  
Reference observation: tunnel-like light ribs, reflective floor, entrance threshold, photo point at the end, visitor path through a branded immersive corridor.  
User goal: adapt visual DNA for a skincare brand pop-up effect image.

Transfer:

- Keep rhythmic light tunnel, entrance framing, reflective floor, visitor path, camera-facing photo point.
- Change brand expression into skincare cues: clean translucency, soft diffusion, water-like material, product plinth.
- Avoid copying original installation brand, exact structure, signage, graphic pattern, and floor plan.

Prompt logic:

- State entrance, installation body, lighting, floor material, product display, visitor scale, and camera/photo point.
- Negative constraints must mention unreadable signage, unsafe crowd clutter, impossible structure, overexposed light strips, and generic sci-fi corridor.

## Case 5: Distinctive Illustrated Poster Risk Review

Input type: described illustrated poster.  
Reference observation: distinctive character, unusual graphic layout, bold hand-lettered title, limited palette, recognizable illustration treatment.  
User goal: identify what can and cannot be copied before making an AI prompt.

Transfer:

- Keep broad mood, color contrast, graphic energy, high-level composition principle, and poster readability.
- Do not copy character design, exact illustration style, title lettering, layout, symbols, or artist-identifying marks.

Prompt logic:

- Output risk map and safer translation before any prompt.
- If writing a prompt, use "inspired by bold limited-palette poster composition" only after replacing protected expression with new subject, new layout, and new graphic language.

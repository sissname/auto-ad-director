# Prompt 转译规则

把品牌研究结果翻成可以控制的视觉变量，而不是直接堆品牌名。

## 先翻译什么

研究结果优先翻成这 8 类：

1. 主体定位：产品 hero、人物肖像、空间入口、静物组合、场景叙事
2. 镜头：俯拍、平视、低机位、长焦、微距、近景、中景、远景
3. 构图：居中、偏置、对称、压边、留白、前景遮挡、纵深
4. 光线：硬光、软光、边缘光、漫射光、窗光、舞台光、冷暖倾向
5. 材质：玻璃、金属、石材、雾面纸、液体、织物、肌肤、木材
6. 色彩：主色、背景色、点缀色、反差强度、黑位与高光倾向
7. 场景：建筑、自然、城市、酒店、家居、展厅、实验室、街头
8. 风险控制：不可照抄元素、假 logo、乱码文字、过度流行滤镜、廉价模板感

## 不要直接翻译成什么

避免直接把研究结论写成：

- “像某品牌一样”
- “官方同款”
- “复刻这张图”
- “完全按这个品牌做”

优先写成：

- “受某品牌公开页面启发的……”
- “保留其公开页面中可见的……”
- “把该品牌公开证据中的……转译为……”

## 转译模板

```text
Evidence-backed visual territory：
- 用一句话定义公开页面里的视觉世界

Prompt translation：
- Subject：
- Camera / lens：
- Composition：
- Light：
- Material：
- Color：
- Environment：
- Human tone：
- Layout / text safety：
- Negative risks：
```

## 变量映射表

### 品牌显得“科技精密”

常见转译：

- 镜头：正面或微低机位，边缘控制严格
- 光线：冷调硬光、边缘光、清晰高光
- 材质：金属、玻璃、阳极氧化、镜面与磨砂对比
- 环境：实验室、极简建筑、整洁城市空间
- 风险：太脏、太拥挤、太多无意义霓虹

### 品牌显得“自然克制”

常见转译：

- 镜头：中近景、微距、留白
- 光线：柔和自然光、漫射、晨昏暖灰
- 材质：石材、木材、纸、肌肤、哑光容器
- 环境：安静室内、自然地景、手工感空间
- 风险：过度商业棚拍、塑料感、过饱和颜色

### 品牌显得“运动动能”

常见转译：

- 镜头：低机位、侧向、裁切感强
- 光线：对比明确、边缘光或运动轨迹感
- 材质：网布、橡胶、发泡、汗感、地面纹理
- 环境：街头、跑道、混凝土、速度感空间
- 风险：陈词滥调的火焰、爆炸、脏乱 cyberpunk

## 文字与 Logo 策略

如果公开页面依赖标题设计或 logo 呈现：

- 优先保留留白区，而不是要求模型生成正确文字。
- 可写“clean title-safe negative space”或“empty label area for post-production”。
- 如果用户必须要品牌字样，提醒后期补字或使用授权设计资产。

## 失败风险的写法

每次至少写 3 类：

1. 不可照抄：logo、包装正面、独特构图、专属插画、具体店装。
2. 做俗风险：廉价黑金、乱加光效、无意义烟雾、随机霓虹。
3. 做偏风险：气质方向反了，比如把克制做成浮夸，把科技做成赛博朋克。

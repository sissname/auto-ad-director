# 案例库

这些案例用于演示如何把官方页面研究转成紧凑、可复用的研究卡。

## 案例 1：Apple 产品主视觉研究

Source focus:

- Newsroom
- iPhone 产品页
- AirPods Pro 产品页

Transfer:

- 精密极简、主体居中、边缘高光、低噪音背景
- 文字区留空，后期叠加更稳

Prompt logic:

- 用中近景 hero 和整洁背景建立高级感
- 不靠复杂环境，靠表面完成度和留白控制来支撑品牌感

Watch:

- 避免白底电商感
- 避免要求模型生成机身文字

## 案例 2：Nike 跑步品类研究

Source focus:

- Newsroom
- Running 分类页
- Running product family 页面

Transfer:

- 动势优先、地面接触真实、材质细节要服务性能
- 局部裁切和低机位能强化速度感

Prompt logic:

- 把运动空间写实化，把动作方向、鞋底接地和表面材质写具体
- 让性能感来自身体和场景关系，而不是烟雾特效

Watch:

- 避免潮流大片化
- 避免悬浮鞋或虚假落地关系

## 案例 3：Porsche 性能叙事研究

Source focus:

- Newsroom
- Press image 页面
- 911 产品页

Transfer:

- 低机位轮廓、道路关系、黄昏斜光、受控反射
- 重点是 silhouette 和 stance，不是复杂道具

Prompt logic:

- 把道路接地和车身曲面放在第一优先级
- 用低角度光线塑造曲线，不靠大面积霓虹制造气质

Watch:

- 避免假徽标
- 避免过度 motion blur 掩盖结构

## 案例 4：Dyson 工程感产品研究

Source focus:

- Newsroom
- Supersonic 产品页
- Cordless 产品页

Transfer:

- 结构清晰、功能件颜色明确、受控工业光
- 材质层次要可区分，不能一把糊成亮面

Prompt logic:

- 用实验室 / 展台语气强化精密感
- 把工程结构、功能组件和材质反差写清楚

Watch:

- 避免家电电商图
- 避免多余烟雾、粒子和夸张特效

## 案例 5：Xiaomi EV 城市性能研究

Source focus:

- 官方公开文章
- 新车型信息页
- 城市科技语境的公开视觉线索

Transfer:

- 清洁速度感、现代城市、产品色明确、湿地反射稳
- 消费电子审美可转译到车身表面和画面留白

Prompt logic:

- 用低机位 hero、城市蓝调和现代建筑建立科技性能气质
- 让产品色和车身表面完成度成为画面重点

Watch:

- 避免传统行政豪华叙事
- 避免 logo、车牌和中文文案乱码

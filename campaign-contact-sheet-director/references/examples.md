# Examples

## 适合谁

- 想直接照着格式产出的人
- 想看四种场景各自怎么拆格的人

## 解决什么问题

- 把抽象的“统一风格、多格镜头”变成可模仿的输出模板

## 示例 1：广告场景 / 9 格

### Brief

- 品牌：新能源汽车
- 任务：做一组城市夜雨发布 campaign
- 格数：9 格
- 平台：Midjourney

### Style Anchor

- 品牌承诺：冷静但昂贵的未来通勤
- 情绪温度：深蓝夜雨、冷银反光、克制张力
- 主色 / 材质：银灰车身、湿地反射、蓝紫霓虹点缀
- 光线逻辑：夜雨逆光 + 路面高反射
- 镜头气质：35mm hero + 85mm detail
- 不可破坏约束：不要黑金奢华，不要赛博脏乱街区

### Grid Plan

- Frame 01：雨夜主 hero
- Frame 02：车灯与水珠 detail
- Frame 03：侧后方 motion
- Frame 04：车内人物关系
- Frame 05：门把手与材质
- Frame 06：停车场环境
- Frame 07：穿过路口的动态镜头
- Frame 08：竖版社媒 crop
- Frame 09：收束封面

## 示例 3：时尚场景 / 12 格

### Brief

- 品牌：独立女装秋冬系列
- 任务：lookbook + 社媒混合素材
- 格数：12 格
- 平台：通用中文模型

### 拆格重点

- 前 3 格：封面 hero、全身造型、半身关系
- 中 3 格：面料 detail、姿态变化、portrait
- 后 3 格：movement、双人关系、场景氛围
- 最后 3 格：竖版封面、横版 banner、缩略图 crop

## 示例 4：空间场景 / 16 格

### Brief

- 项目：商场中庭节庆装置
- 任务：向甲方提案一整套 contact sheet
- 格数：16 格
- 平台：即梦 + 通用中文模型

### 拆格重点

- Frame 01-02：入口与远景
- Frame 03-04：主装置 hero
- Frame 05-06：路径节点
- Frame 07-08：人与装置关系
- Frame 09-10：材质与灯光 close-up
- Frame 11-12：夜景氛围
- Frame 13-14：拍照点与传播位
- Frame 15-16：标题区与封面备选

## 常见坑

- 示例可以模仿结构，不要直接照搬主体和品牌名
- 先保留 style anchor，再替换具体对象
- 格数越多，越要让最后几格承担传播和裁切任务

# Scenario Playbooks

## Mall Display

- 目标：远距离识别、快速停留、带动进店或中庭事件感。
- 强项：入口门头、中心主装置、扶梯口视线拦截、夜间发光。
- 风险：中庭尺度吃不住、店招过多抢画面、层高被浪费。
- Prompt 关键词：中庭层高、扶梯对视、远观识别、品牌事件岛、夜间发光体块。

## Pop-up

- 目标：短周期事件感、品牌记忆、单店导流、社媒传播。
- 强项：高识别门头、可排队拍照点、可拆装材料、强概念色。
- 风险：太像展会桁架、只有装饰没有销售关系、材质廉价。
- Prompt 关键词：临时但精致、快装模块、可移动陈列、导流前台、打卡动线。

## Exhibition

- 目标：内容叙事、分区浏览、主题层层展开。
- 强项：展墙、展柜、图文节点、观看节奏、知识型体验。
- 风险：只像商场打卡装置，不像展陈；信息位混乱；动线过散。
- Prompt 关键词：序厅、主题分区、展墙层次、观看停留、节奏性导览。

## Immersive Corridor

- 目标：通过式沉浸、强穿越感、从入口到终点的连续体验。
- 强项：连续体块、灯光包裹、地面导光、终点焦点装置。
- 风险：只是灯带隧道模板、照片好看但现场难走、视觉疲劳。
- Prompt 关键词：连续节奏、穿越通道、包裹光、地面导向、终点仪式感。

## 选择提醒

- `Mall Display` 先看远观和中庭气场。
- `Pop-up` 先看品牌记忆和排队传播。
- `Exhibition` 先看内容节奏和分区信息。
- `Immersive Corridor` 先看连续体验和终点高潮。

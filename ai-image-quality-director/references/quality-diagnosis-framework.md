# 质量诊断框架

每次审查 AI 生图时，都按同一顺序判断，避免被风格词带偏。

## 审查顺序

1. 结构与主体完整性
2. 真实感与物理逻辑
3. 构图与视觉层级
4. 光线与材质表现
5. 品牌气质与风格一致性
6. 商业可用性
7. 文字 / logo 风险
8. 可修复性

## 评分卡

每项按 1-5 分打分：

```text
结构与主体完整性：
真实感与物理逻辑：
构图与视觉层级：
光线与材质表现：
品牌气质与风格一致性：
商业可用性：
文字 / logo 风险：
可修复性：
```

决策建议：

- 平均 4.5-5：可直接保留，最多小修。
- 平均 3.8-4.4：概念有效，建议修。
- 平均 3.0-3.7：只在某个亮点很强时才抢救。
- 低于 3.0：优先重做，不要继续堆词。

## 各项判断标准

### 结构与主体完整性

看主体有没有明显变形、解剖错误、比例异常、边界融化、重复部件、遮挡错位。

典型失败：

- 手多一根手指
- 包装瓶身左右不对称
- 汽车轮胎漂浮
- 空间透视线打架

### 真实感与物理逻辑

看重力、接触阴影、反射、折射、景深、材质反应、远近关系是否合理。

典型失败：

- 物体像贴在背景上
- 金属像塑料
- 玻璃没有厚度
- 水面反射逻辑混乱

### 构图与视觉层级

看画面有没有一个明确主角，观者视线是否被正确引导，裁切是否伤害主体。

典型失败：

- 主体被背景抢走
- 左右信息量失衡
- 标题位和主体打架
- 缩略图下主体识别不清

### 光线与材质表现

看光源方向、反差关系、高光控制、阴影细节和材质响应是否一致。

典型失败：

- 光从多个不合理方向同时打来
- 面部和产品不是同一个光环境
- 高光太脏，材质边界糊

### 品牌气质与风格一致性

看风格是否符合 brief 的价位、受众、品牌气质和品类语境。

典型失败：

- 想做奢侈香水，却像廉价电商海报
- 想做科技品牌，却用了老派影楼布光
- 想做儿童品，却太冷太危险

### 商业可用性

看画面是否能真正拿去做 KV、海报、社媒图、投放素材或提案页。

重点检查：

- 有没有能放文案的位置
- 不同比例裁切后还能不能用
- 缩略图是否还能认清主体

### 文字 / logo 风险

看模型是否被要求生成精确文字、品牌字样、包装文案、招牌、车牌或 UI 文本。

默认策略：

- 推荐留出干净区域后期补字
- 推荐 blank area、clean label area，而不是让模型生成长文本

### 可修复性

判断是“小补丁能救”，还是“世界观已经错了必须重做”。

优先修的，是少量改动就能明显提升的失败点。

# Prompt Bible Examples

## 完整交付包骨架

```text
Project：
Scenario：
Audience：

Style anchor：
[统一空间语言]

Zone strategy：
- Entrance：
- Installation Device：
- Lighting：
- Floor Graphic：
- Traffic Flow：
- Photo Point：

Prompt stack：
- Entrance Prompt：
- Device Prompt：
- Lighting Prompt：
- Floor Graphic Prompt：
- Traffic Flow Prompt：
- Photo Point Prompt：

Proposal summary：
- 核心概念：
- 体验路径：
- 品牌传播动作：

Negative risks：
- 比例风险：
- 动线风险：
- 材质风险：
- 俗套风险：
```

## 适用场景 1：商场中庭快闪

- 入口负责远观识别和事件开场。
- 主装置负责制造停留与拍照价值。
- 地贴和灯光负责把人送向门店或互动区。

## 适用场景 2：品牌展陈

- 序厅负责建立主题。
- 分区负责内容层层展开。
- 拍照点应从展陈主叙事里长出来，不要额外拼贴。

## 适用场景 3：沉浸式通道

- 入口先给第一道门槛感。
- 通道中段给节奏变化。
- 终点必须有高潮或奖励式画面。

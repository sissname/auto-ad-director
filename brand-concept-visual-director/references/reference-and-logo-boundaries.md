# 参考图与 Logo 边界

品牌方向稿经常会混入参考图、草图、SVG、竞品截图和用户临时画的符号。必须把探索和最终设计分开。

## 可以借鉴

- 光影关系。
- 构图节奏。
- 色彩温度。
- 材质感。
- 用户情绪。
- 图形密度。
- 空间/物件关系。

## 不应复制

- 竞品 logo。
- 精确字体和字标。
- 官方品牌图案。
- 具体人物脸和肖像。
- 独特插画角色。
- 完整海报版式。
- 可识别商业包装。

## SVG / 草图处理

当用户提供 SVG、草图或简单图标时：

- 把它当成“方向线索”，不是专业 logo。
- 提取意图：圆形、开口、陪伴、阅读、连接、流动、对称、手写感等。
- 输出方向稿 prompt，而不是承诺最终标志。
- 明确下一步需要字体、网格、可读性、小尺寸、黑白版和商标检索。

## 安全文案

可使用：

```text
这轮输出是品牌方向稿，不是最终 logo。AI 图可帮助判断气质、符号母题和视觉氛围，但最终标志仍需要在矢量设计、字体、可读性和商标风险层面单独打磨。
```

明确判断：这不是最终 logo，而是前期视觉方向探索。

## 文字和 Logo 生成策略

- 让图像模型留出干净文字区。
- 不要求生成精确品牌名。
- 可以要求“抽象符号方向”“干净图形占位”“无可读文字”。
- 最终文字、logo、品牌名放到设计软件中处理。

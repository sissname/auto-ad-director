# Examples

## 示例 1：商场入口门头

用户可能会说：

```text
做一个夏日航空主题的商场入口门头，要有事件感，但不要廉价乐园风。
```

输出重点：

- 用“航站楼登机门”而不是“卡通飞机”做体块语言。
- 入口要有抬头识别和夜间发光轮廓。
- 留出可拍正面合影的站位。

## 示例 2：快闪主装置 + 拍照点

用户可能会说：

```text
给美妆联名快闪做一个主装置和打卡点，要能导流进店。
```

输出重点：

- 主装置负责品牌记忆。
- 拍照点负责社媒传播。
- 两者必须共享同一色彩和材质系统。

## 示例 3：沉浸通道

用户可能会说：

```text
用一张现场走廊照片，帮我做成品牌发布会的沉浸通道方向。
```

输出重点：

- 先识别可包裹的墙、顶、地关系。
- 再建立从入口到终点的连续节奏。
- 不要让画面只剩灯带，需要结构体块和终点焦点。

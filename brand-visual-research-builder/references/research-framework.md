# 品牌视觉研究框架

用这份参考把“看官方页面”变成结构化研究，而不是堆品牌形容词。

## 目标

输出三类东西：

1. 来源记录：以后还能回查的官方链接。
2. 观察结论：页面到底传达了什么视觉领地。
3. Prompt 变量：哪些能转成镜头、光线、材质、颜色、环境和避免项。

## 来源优先级

优先顺序固定如下：

1. 官方首页 / 顶部品牌页
2. 官方产品页 / 系列页
3. 官方新闻稿 / Newsroom / Press release
4. 官方媒体中心 / Lookbook / Media assets index
5. 官方品牌故事 / 设计理念 / Store experience
6. 用户明确提供的品牌 PDF、提案或内部参考
7. 第三方媒体或零售页

默认不要用第 7 类去覆盖前 1-5 类的证据。

## 研究顺序

### 1. 先定任务

- 这次研究是给什么交付服务：海报、产品主视觉、空间效果图、社媒广告、Campaign 提案。
- 输出需要多深：快速研究库、深挖品牌、品牌对标、只做研究。

### 2. 先看品牌层

记录：

- 品牌整体给人的第一视觉印象是什么。
- 页面是极简、运动、工艺、科技、自然、收藏级、生活方式，还是别的领地。
- 哪些元素反复出现：材质、色温、背景类型、镜头距离、人物状态、版式密度。

### 3. 再看产品层

记录：

- 产品是被当作“功能物”“身份物”“情绪物”“工艺物”还是“科技物”来拍。
- 主体被摆在什么环境：纯净背景、建筑空间、自然地景、城市语境、生活场景。
- 画面是强调外形轮廓、细节纹理、交互动作、情绪氛围还是系列一致性。

### 4. 再看新闻与媒体层

记录：

- 新闻稿更强调发布事件、技术突破、联名故事还是生活方式叙事。
- 媒体页里的共通视觉手法：hero angle、留白区、色彩纪律、模特状态、道具密度。
- 这类页面通常能帮助判断品牌“官方最愿意被看见的样子”。

## 观察维度

每次都按这 7 项记录：

1. 视觉领地：一句话总结品牌在公开页面中的气质。
2. 构图与镜头：正面、俯拍、低机位、长焦、微距、居中、留白、版式空间。
3. 光线：硬光、软光、边缘光、阴天光、科技冷光、金色自然光、商业修图感。
4. 材质：玻璃、金属、皮革、石材、织物、肤质、雾面、镜面、液体。
5. 颜色：主色、辅色、点缀色、背景色、对比度。
6. 场景与叙事：室内、街头、自然、展厅、工作室、家居、旅途、仪式感。
7. 风险：哪些元素太像“品牌本体表达”，只能借气质不能借形。

## 记录格式

每个品牌至少保留：

```text
品牌 / 产品：
研究目标：

来源：
1. URL - 页面类型 - 核心证据
2. URL - 页面类型 - 核心证据

观察：
- 视觉领地：
- 构图与镜头：
- 光线：
- 材质：
- 颜色：
- 场景与叙事：

- 应保留：
- 可替换：
- Negative risks：
```

## 判断好坏的标准

研究输出算合格，至少满足：

- 有真实可回查的官方来源链接。
- 不只是“高级、极简、质感好”这类空话。
- 至少能落到 5 个可控变量：镜头、构图、光线、材质、颜色。
- 明确指出不能照抄的元素。
- 能支持下一步写 prompt 或方向稿，而不是停留在摘要。

# Proposal Summary Playbook

把空间方向稿翻成客户能快速理解的提案摘要，不要停留在“高级、沉浸、未来感”这类空词。

## 提案摘要固定六段

1. `核心概念`
   - 说明这次空间不是单纯装饰，而是在卖什么品牌故事、活动主题或客流动作。
2. `入口吸引动作`
   - 说明远观如何被看见、近看如何停下、抬头或合影时先记住什么。
3. `主装置价值`
   - 说明主装置负责记忆、互动、展陈还是社媒传播，不要只说“大装置”。
4. `动线组织`
   - 说明人从哪里进、在哪里停、怎么绕、如何走向下一节点或门店。
5. `传播与转化`
   - 说明拍照点、导流点、排队点、内容节点怎样服务传播或销售。
6. `执行风险`
   - 明确层高、柱网、扶梯视线、吊挂条件、材质预算感、夜景光环境等风险。

## 过会摘要写法

### 一句话版

```text
用一句话说清：这套空间如何在第一眼吸引、停留阶段说服、离场前促成传播或导流。
```

### 三段版

```text
提案摘要：
- 核心概念：
- 空间主叙事：
- 入口吸引动作：
- 主装置价值：
- 动线组织：
- 拍照传播机制：
- 执行风险：
```

### 决策版

适合用户问“为什么这个方向值得继续做”时使用：

```text
为什么成立：
- 远观记忆点：
- 近看停留点：
- 社媒传播点：

为什么不是通用模板：
- 场地特征：
- 品牌特征：
- 动线特征：

下一轮优先验证：
- 先出哪一区效果图：
- 哪个风险最该先压测：
```

## 常见空话替换表

- 不要只写“沉浸感强”。
  改成：入口压低门槛感，中段用连续光带和体块节奏包裹视线，终点给仪式性焦点。
- 不要只写“高级感”。
  改成：控制材质数量、收紧主色、减少廉价图案堆叠，保留克制但强识别的门头与主装置关系。
- 不要只写“导流效果好”。
  改成：地面引导和灯光焦点把人从入口送到主装置，再把停留人群推向门店或互动台。

## Fail if

- 提案摘要只有审美形容词，没有入口、主装置、动线和传播分工。
- 没有写场地限制，像任何白盒空间都能成立。
- 没有写执行风险，导致摘要只像概念文案。
- 没有说明这套空间为什么服务商业目标。

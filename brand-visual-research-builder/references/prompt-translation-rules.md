# Prompt Translation Rules 参考

本文件说明如何把品牌研究观察转成后续 prompt director 可直接使用的控制变量。

## 转译总原则

- 先保留关系，再保留造型：优先保留光线关系、材质关系、空间关系和主次关系。
- 先写控制，再写形容：用镜头、构图、材质、色温、环境去替代“高级、极简、奢华”。
- 先去品牌化，再做方向化：研究来源可以是官方页面，但输出要避免变成“直接复刻品牌资产”。

## 观察到控制变量的映射表

| 研究观察 | 转译字段 | 推荐写法 | 不推荐写法 |
| --- | --- | --- | --- |
| 大量留白，主体集中 | 构图 | 主体占画面 40%，保留整洁留白区 | 极简高级构图 |
| 冷白边缘高光 | 光线 | 冷色边缘光，轮廓清晰，背景压暗 | 科技感灯光 |
| 磨砂金属与玻璃 | 材质 | 拉丝金属、干净玻璃高光、控制反射 | 高级材质 |
| 页面强调功能结构 | 镜头 | 中近景产品特写，功能结构清晰 | 拍得很专业 |
| 真实使用场景克制 | 空间 | 控制环境元素，不堆砌道具，留后期文案区 | 有氛围的环境 |
| 官方文案简短克制 | 文字策略 | 图内不要求生成可读文字，预留空白 | 把官网标语打在画面上 |

## 输出字段建议

每次转译至少输出：

- Camera
- Composition
- Light
- Material
- Color
- Space / set
- Talent / object behavior
- Typography / logo policy
- Negative constraints

## 镜头规则

- 科技 / 工业品牌：更适合中近景、平视或低机位、线条干净。
- 运动品牌：更适合低机位、动势拉开、局部裁切、速度感环境。
- 奢侈 / 高端品牌：更适合长焦压缩、克制动作、受控反射、低密度环境。
- 家居 / 护理 / 生活方式品牌：更适合柔和光、平缓镜头、自然尺度关系。

## 光线规则

- 不要只写“电影感”。要写清楚方向、硬度、反差、色温和目的。
- 如果官方页面更强调材质，就优先写边缘高光和表面控制。
- 如果官方页面更强调人和场景，就优先写环境光层次和主体分离。

## 颜色规则

- 先写底色，再写点缀色，再写颜色比例。
- 如果品牌页面颜色很节制，不要在 prompt 里加入多色炫光。
- 如果品牌有稳定主色，只把主色当作局部强调，不默认整张图都染色。

## 文字 / logo 规则

- 研究结论里可以写“品牌常使用简短克制文案”。
- prompt 里应改写为“预留干净文字区”或“保留空标签区，后期补字”。
- 不要求模型生成精确 logo、标语、包装文字、按键字样。

## Failure Risks 写法

最少包含：

- 调性跑偏成什么
- 最脆弱的结构或材质是什么
- 文字 / logo / 标识上最容易出什么问题
- 哪些元素只适合“受启发”，不适合“照搬”

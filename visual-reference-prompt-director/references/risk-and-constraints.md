# Risk and Constraints

Use this file when a reference may be copied too literally or when generated results are likely to fail.

## Do-Not-Copy Elements

Flag these before writing prompts:

- Exact brand marks, logos, slogans, UI screens, packaging labels, license plates, or readable text.
- Identifiable private people or celebrity likenesses unless the user has permission and the request is allowed.
- Distinctive artwork, illustration style, campaign layout, poster composition, or character design that functions as protected expression.
- Official product imagery where the user wants to recreate the exact shot.
- Cultural/religious symbols used as decorative texture without context.

Safer move: translate into non-identical visual rules, such as "clean sans-serif label area" or "museum-like central product symmetry" rather than copying the original mark or layout.

## Generation Failure Risks

Common risks:

- Text and logo gibberish.
- Crooked product geometry, warped wheels, extra fingers, broken faces, melted jewelry, distorted packaging.
- Reflections that contradict the light source.
- Glass/water/metal becoming noisy or plastic.
- Overcrowded props fighting the primary subject.
- Reference mood overpowering the new subject.
- Generic luxury: black background, gold rim light, smoke, marble, and no specific product logic.

## Negative Constraint Patterns

Use concise negatives:

- no readable text, no fake logo, no watermark
- no distorted hands, no extra fingers, no melted facial features
- no warped geometry, no broken reflections, no duplicated subject
- no cheap HDR, no plastic over-sharpening, no random neon
- avoid copying exact reference layout, artwork, brand marks, or identifiable person

For Chinese prompts:

```text
避免可读文字、乱码 logo、水印、畸变结构、错误反射、廉价 HDR、过度锐化、随机霓虹色，不复制参考图中的具体品牌标识、人物身份、图案和版式。
```

## Safer Translation Formula

When the reference is sensitive, answer with:

1. What can transfer: mood, light direction, contrast, lens feel, palette discipline, material response.
2. What must change: exact subject identity, logos, text, artwork, layout, face, distinctive design.
3. How to rebuild: new subject, new environment, comparable light and composition logic.
4. Prompt constraints: explicit safe translation and negative constraints.

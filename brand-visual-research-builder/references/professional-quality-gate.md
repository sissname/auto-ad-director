# 专业质量门

当研究结果要进入提案、交付包、团队评审或长期研究库时，用这份质量门做最后一轮筛查。

## 证据质量

- 是否至少有 2 个官方来源链接。
- 是否同时覆盖了产品层和品牌/新闻层。
- 是否标明来源等级：A / B / C / D。
- 是否把“看见的证据”和“你的推断”区分开了。

## 研究结论质量

- 是否有一句真正能概括品牌公共视觉领地的话。
- 是否具体写出了镜头、构图、光线、材质、色彩、场景、人物状态。
- 是否能被后续 prompt 直接消费，而不是需要再次猜测。

## 合规与风险

- 是否明确说了“不保存原图、不宣称官方授权”。
- 是否指出至少 1 类不能照抄的品牌要素。
- 是否指出至少 2 类容易做俗或做偏的方向。
- 是否提醒 logo、字体、包装正面和独特版式的风险。

## 可交付性

- 用户拿到这份研究，是否能直接开始写 brief 或 prompt。
- 是否说明“适合做什么 / 不适合做什么 / 还缺什么资料”。
- 对标任务是否真正写出了差异，而不是并排抄品牌形容词。

## 快速判定

### 可以过

- 来源清楚
- 变量具体
- 风险说清
- 结论能服务下一步产出

### 不能过

- 只有品牌故事，没有视觉变量
- 只有 mood 词，没有镜头/材质/光线
- 没有来源
- 暗示官方授权
- 没有 failure risks

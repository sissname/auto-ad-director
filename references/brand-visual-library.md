# Brand Visual Library

Use this reference when the user names a car brand or wants sharper brand-level direction. These are research-backed prompt heuristics, not official brand guidelines. If the user supplies real brand guidelines, use those first. For source links and evidence notes, read `campaign-research-bank.md`.

## How to Use

Start with:

```text
Brand read: [brand/model]
Evidence-backed visual territory: [one concise phrase]
Official evidence cues: [source-backed cues from campaign-research-bank.md]
Prompt translation rules: [locations, light, lens, material, human tone]
Failure risks: [what would make it feel generic or off-brand]
```

If the brand is unknown, map it to the closest archetype in `brand-archetypes.md`.

## Chinese EV Brands

### Xiaomi

- Evidence-backed visual territory: tech-lifestyle performance, clean speed, consumer-electronics polish.
- Official evidence cues: Xiaomi EV public pages emphasize SU7/YU7 product identity and strong product color naming such as Aqua Blue, Verdant Green, and Mineral Gray.
- Prompt translation rules: use glossy paint, wet asphalt, phone-like glass reflections, UI-like clean negative space, Shanghai/Shenzhen modern roads, bright product-color accents, precise vehicle geometry.
- Failure risks: old-money chauffeur luxury, fake racetrack drama, cluttered cyberpunk, random Chinese text, over-complicated neon.

### NIO

- Evidence-backed visual territory: executive smart luxury, warm premium technology, calm confidence.
- Official evidence cues: ET9 is publicly positioned as a smart electric executive flagship with comfort and refined technology.
- Prompt translation rules: use glass pavilions, quiet CBD arrival, lounge-like interiors, dusk city light, refined cabin comfort, composed professional owners.
- Failure risks: racing aggression, cold sci-fi sterility, messy grit, generic luxury without human-centered warmth.

### Li Auto

- Evidence-backed visual territory: family flagship comfort, spacious premium intelligence.
- Official evidence cues: Li L9 is positioned as a flagship smart SUV and six-seat flagship family SUV.
- Prompt translation rules: use readable cabin space, warm morning/golden-hour light, home/resort/weekend contexts, calm family presence, safe road staging, confident SUV stance.
- Failure risks: dangerous speed cues, lonely fashion editorial, dark thriller mood, cramped interiors, fragile luxury abstraction.

### Zeekr

- Evidence-backed visual territory: design-forward urban performance, sharp new-luxury.
- Official evidence cues: use this as an archetypal heuristic unless user provides official Zeekr material.
- Prompt translation rules: use art districts, angular plazas, concrete architecture, night ramps, high-contrast reflections, black/silver surfaces, electric accent color.

### XPeng

### BYD

- Evidence-backed visual territory: broad-market technology confidence, scale, trust.
- Official evidence cues: use this as an archetypal heuristic unless user provides official BYD material.

## Global Brands

### Audi

- Evidence-backed visual territory: progressive precision, premium lighting, architectural order.
- Official evidence cues: Audi public material foregrounds MediaCenter product imagery and A6 e-tron lighting design, including illuminated rings and digital OLED themes.
- Prompt translation rules: use glass architecture, urban plazas, cool highlights, silver/black paint, crisp hard shadows, light-bar macro details, disciplined composition.
- Failure risks: messy neon, fake logos, cartoon futurism, lighting effects that obscure vehicle geometry.

### Porsche

- Evidence-backed visual territory: timeless performance, sculpted motion, driver desire.
- Official evidence cues: Porsche newsroom and press-image territory centers on performance, stance, body curves, and driving emotion.
- Prompt translation rules: use mountain roads, asphalt texture, low raking light, warm garages, track-adjacent locations, brake-light accents, road contact, clean emblem area.
- Failure risks: fake badges, generic red sports-car cliche, sterile EV showroom mood, excessive motion blur, floating wheels.

### BMW

- Evidence-backed visual territory: dynamic driver energy, confident sport-luxury.
- Official evidence cues: use as archetypal heuristic unless user provides official BMW campaign material.
- Prompt translation rules: use city avenues, tunnels, mountain switchbacks, sharp front highlights, road texture, directional motion, front three-quarter stance.
- Failure risks: passive catalog stillness, fake grille details, over-soft lifestyle mood.

### Mercedes-Benz

- Evidence-backed visual territory: refined executive luxury, comfort, status, silence.
- Official evidence cues: S-Class and Mercedes-Maybach public material emphasizes refined detail, luxury, comfort, and elevated standards.
- Prompt translation rules: use hotel entrances, museum districts, polished stone, evening boulevards, soft highlights, chrome/black paint, warm interior spill, longer-lens calm.
- Failure risks: street-race energy, noisy youth styling, harsh neon, random grille/badge text, cheap studio shine.

### Tesla

- Evidence-backed visual territory: minimal tech, clean futurism, direct product clarity.
- Official evidence cues: use as archetypal heuristic unless user provides official Tesla material.
- Prompt translation rules: use desert roads, clean suburbs, minimal charging stations, open highways, glass homes, white/black surfaces, sparse backgrounds.
- Failure risks: overstyled fashion luxury, ornamentation, cluttered visual worlds, fake interface text.

### Lexus

- Evidence-backed visual territory: crafted calm, Japanese premium, quiet refinement.
- Official evidence cues: use as archetypal heuristic unless user provides official Lexus material.
- Prompt translation rules: use modern villas, stone/water/wood, rain gardens, quiet city entrances, satin paint, warm cabin, smooth reflections.
- Failure risks: harsh aggression, cheap neon, loud fashion styling, brittle sci-fi surfaces.

## Model-Type Overrides

- Supercar/coupe: add performance tension even if brand is luxury.
- Flagship sedan: add silence, status, privacy, longer lens, calmer body language.
- SUV/MPV: add space, ground confidence, cabin readability, human warmth.
- Compact EV: add agility, city convenience, approachable tech.
- Concept car: add gallery/architecture, but keep wheels grounded and reflections plausible.

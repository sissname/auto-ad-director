# 来源留档与合规边界

这份参考用于控制品牌研究时的证据质量和风险边界。

## 必须保留什么

只保留这些：

- 页面链接
- 页面类型：产品页 / 新闻稿 / 媒体中心 / 故事页 / 店铺页
- 页面可见的观察结论
- 你从观察结论转出来的 prompt 规则
- failure risks 和不可照抄项

## 不要保留什么

默认不保存，也不要保存：

- 官方原图
- 官网页面截图
- 下载的媒体素材包
- 品牌 logo 文件
- 品牌字体文件
- 可直接复用的海报版式
- 任何会让输出看起来像“官方授权交付”的包装

## 必须说清楚的边界

输出里优先用这些说法：

- “基于品牌公开官方页面的观察”
- “品牌启发的视觉领地”
- “公开页面可见的视觉证据”
- “适合转译的气质与变量”

避免这些说法：

- “官方品牌规范如下”
- “这就是该品牌的官方视觉标准”
- “可直接视为官方 campaign 规则”
- “已获品牌授权”

## 什么时候要升级提醒

以下场景必须提醒用户还需要正式官方材料：

- 用户要求精确 logo、标题字、口号、包装正面
- 用户要求严格合规的品牌提案
- 用户要复刻某次已发布 campaign 的画面结构
- 用户要输出对外商用、法务敏感或需审批的素材

此时要明确：

```text
公开页面研究可以提供视觉方向，但不能替代正式 brand guideline、授权素材或法务审批版本。
```

## 来源可信度标记

按下面的等级标注：

- A：官方产品页、官方新闻稿、官方媒体中心
- B：官方故事页、官方店铺/空间页、官方品牌哲学页
- C：用户提供但未核实来源的 PDF、截图、二手整理
- D：基于品牌行业印象的保守推断

默认优先引用 A，再用 B 补充空间或叙事感。C 和 D 只能明确标注后使用。

## 高风险元素处理

这些元素默认只做抽象总结，不做复刻指令：

- logo 与字标
- 独特插画角色
- 受保护的包装正面布局
- 可识别的摄影签名风格
- 店铺平面图和展陈结构
- 完整 campaign 标题区和文案位置

## 最安全的交付方式

默认交付：

- 来源链接
- 一句话视觉结论
- 可迁移的镜头、光线、材质、色彩、场景规则
- 不可迁移的风险点

不要默认交付：

- “和官方一模一样”的 prompt
- 可直接复刻成品图的版式说明
- 假装已获得内部品牌资料后的语气

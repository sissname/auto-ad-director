# 案例库

以下是文字化案例，不包含真实品牌素材或原图。

## 案例 1：阅读陪伴品牌

输入：面向年轻人的阅读陪伴产品，希望温柔、可信、不过度学术。  
方向：

- 窗光纸张：自然光、纸张、低饱和暖色。
- 夜间陪伴：柔和台灯、深蓝阴影、安静独处。
- 轻社群：多人但不吵闹，圆桌、便签、书页。

风险：容易变成教育机构、鸡汤社媒、复古书店。

## 案例 2：护肤新品牌

输入：水感、敏感肌、科学但不医院。  
方向：

- 透明实验室：半透明材质、清洁光、少量水珠。
- 皮肤呼吸：柔焦肌理、自然肤色、空气感。
- 日常浴室：晨光、陶瓷、水汽、干净生活方式。

风险：医院感、廉价水滴、过度白蓝科技。

## 案例 3：咖啡生活方式品牌

输入：社区咖啡、不是精品咖啡的冷感，而是日常关系。  
方向：

- 街角暖光：门口、木椅、晨光。
- 手写菜单：但不要求模型生成可读字。
- 桌面关系：杯子、手、报纸、邻里感。

风险：网红咖啡店模板、过度复古、假文字。

## 案例 4：AI 工具品牌

输入：效率工具，想要聪明、清爽、可信，不想像 SaaS 模板。  
方向：

- 清晰工作台：真实桌面、轻 UI 光感、少量图形层。
- 可视化思考：纸张、线索、透明标注。
- 安静自动化：低对比背景、精准高光、秩序感。

风险：蓝紫渐变 SaaS、抽象光球、无意义仪表盘。

## 案例 5：品牌符号探索

输入：用户给了一个简单 SVG 圆形开口符号，想探索 logo 气质。  
处理：

- 不把 SVG 当最终 logo。
- 提取“开放、连接、循环、入口”的母题。
- 输出方向图：空间入口、纸张开口、柔和环形光、抽象品牌符号占位。

风险：直接复制草图、承诺最终 logo、忽略小尺寸和商标风险。

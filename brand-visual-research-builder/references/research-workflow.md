# 品牌视觉研究工作流

本文件定义如何把官方公开页面整理成可复用的视觉研究库。

## 1. 先锁定研究对象

先回答四件事：

- 研究品牌是谁，是否限定到某个产品线。
- 研究用途是什么：提案、出图前置、对标、方向筛选，还是失败复盘。
- 研究颗粒度是什么：品牌总调性、某条产品线、某次发布、某组空间。
- 当前证据来自哪里：用户给的链接、你自己能读到的官网，还是只有品牌名。

## 2. 建立来源清单

优先抓 3 到 6 个官方页面，不求多，但求互补。

推荐组合：

1. 官网首页或品牌总页：看整体视觉节奏。
2. 新闻 / newsroom：看品牌怎样叙述自己。
3. 媒体中心 / press / image bank：看官方最愿意公开的视角和控制方式。
4. 产品页：看材料、颜色、近景细节和可卖点。
5. 空间 / 门店 / about：看场景、陈列、空间语气。

如果没有 newsroom 或 media center，不要编造；改成“产品页 + 品牌页 + 官方空间页”的组合。

## 3. 对每个页面做四层记录

每个链接至少记录：

- 页面类型：官网 / newsroom / media / product / space / about
- 页面作用：为什么值得读
- 视觉证据：你真正看到或能直接从页面结构中提炼的事实
- 研究价值：这条证据之后能转成什么控制变量

不要只记“高级、简洁、科技感”。要写成可执行语言，例如：

- 大量留白，主体通常占画面 35% 到 50%
- 光线偏柔和边缘高光，强调金属或玻璃轮廓
- 背景控制干净，文字区域留空，适合后期叠字

## 4. 把证据聚类成视觉系统

把零散观察归到以下字段：

- 构图与景别
- 镜头高度与距离
- 光线方向、硬度、色温
- 材质与表面反应
- 颜色纪律
- 场景与空间语气
- 人物 / 使用者气质
- 文案 / logo 的安全处理

如果某字段没有足够证据，不要硬填。宁可写“暂无明确证据”。

## 5. 写 Prompt Translation Rules

研究库的关键不是“观察很多”，而是“能转成后续可执行规则”。

每个字段都要落到控制变量：

- 镜头：低机位、平视、中焦、长焦、俯拍、近距特写
- 光线：硬侧光、柔和顶光、冷色边缘光、暖色室内漫射
- 材质：拉丝金属、雾面塑料、透明玻璃、湿地反射、石材台面
- 颜色：高纯度点缀、低饱和中性色、品牌主色只占局部
- 空间：画廊、实验室、跑道、酒店入口、安静家居
- 文字 / logo：留空、后期补字、避免要求模型渲染可读文案

## 6. 写 Failure Risks

`Failure Risks` 不是免责声明，而是避免出图跑偏的控制条件。

至少写三类：

- 调性跑偏：容易变成哪种廉价或错误风格
- 结构翻车：哪些物理、透视、材质最容易假
- 权利风险：哪些版式、商标、标语、人物或装置不能照抄

## 7. 收束成 Compact Research Bank

最终研究库应当足够紧凑，别人读完就能接着用，而不是重新研究一遍。

推荐字段：

- Brand
- Research angle
- Source links
- Observation summary
- Prompt Translation Rules
- Failure Risks
- Safe wording

## 8. 交付时要显式声明边界

必须保留三条边界：

- 这是基于官方公开页面的非官方研究结论。
- 不保存原图，只保留源链接和文字观察。
- 研究结论用于方向转译，不代表品牌授权或正式 brand guideline。

# 迭代策略

这个参考用于决定下一轮怎么改，而不是简单地“再润色一下”。

## 结果复盘

先用这四行复盘当前图：

```text
Keep：已经成立的优点
Fix：必须先修的 1-3 个问题
Protect：修图时不能丢的东西
Next move：最小有效改动
```

## 迭代优先级

1. 主体结构与解剖
2. 接地感、透视和真实感
3. 构图层级
4. 光线与材质
5. 品牌气质
6. 文案位、logo 位、裁切位
7. 风格细节

## A/B 测试规则

- A 版：保守修复版。尽量保留原构图，只修致命问题。
- B 版：强化版。保留概念，但在光线、场景或机位上更果断。
- C 版：探索版。只有用户明确要时才给，且只能更换一个主变量。

不要做“只是换几个形容词”的假 A/B。

## 版本记录模板

```text
Version：
Changed：
Reason：
Expected effect：
Risk：
```

示例：

```text
Version：V2
Changed：把“未来感玻璃大厅”改成“低机位 50mm、黑色石材地面、单一侧逆光、明确接触阴影”。
Reason：V1 主体漂浮，空间反射太乱。
Expected effect：主体更稳，材质更像真实摄影。
Risk：空间戏剧性会下降。
```

## 修还是重做

符合以下条件时优先修：

- 只有 1-2 个致命问题
- 品牌气质基本对
- 主体和构图有明显优点

符合以下条件时优先重做：

- 主体结构、光线逻辑、品牌气质同时错
- 生成的是错误品类
- 需要大改世界观才可能救回

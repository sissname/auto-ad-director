# Spatial Installation Framework

## 目的

把“空间感觉”拆成可执行的提案与效果图语言，而不是停留在概念口号。

## 六区交付法

任何空间项目默认拆成六个区：

1. 入口 `Entrance`
2. 主装置 `Installation Device`
3. 灯光 `Lighting`
4. 地贴 / 地面引导 `Floor Graphic`
5. 动线 `Traffic Flow`
6. 拍照点 `Photo Point`

如果用户只要求其中一部分，也要说明这一部分与其余五区怎么对齐。

## 统一 Style Anchor 的 8 个锚点

1. 核心叙事：这不是“好看”，而是什么故事。
2. 体块语言：拱、环、舱体、折板、悬浮、幕帘、岛台、层层退台。
3. 主要材质：金属、半透膜、亚克力、织物、镜面、木饰面、灯箱膜。
4. 主色和点色：主色不能超过 2 组，点色只负责节奏。
5. 光感策略：洗墙、轮廓线、体块背光、互动发光、地面导光。
6. 观看距离：远观识别、中距离停留、近距离拍照分别看什么。
7. 人群动作：通过、停留、绕行、进入、排队、合影。
8. 品牌感：未来科技、温暖手作、潮流事件、收藏展览、家庭互动等。

## 入口 / 主装置 / 灯光 / 地贴 / 动线 / 拍照点

### 入口

- 负责第一识别和主题命名。
- 优先处理尺度、门框感、视线抬头点和夜间可见性。

### 主装置

- 负责记忆点和中心事件。
- 先定主形，再定互动，再定材质细节。

### 灯光

- 不是单独装饰；要服务识别、聚焦、氛围和拍照。
- 说明主光、辅光、轮廓光、地面光分别服务哪里。

### 地贴

- 负责把概念落到脚下，给动线节奏和导流箭头。
- 不要只写图案，要写落位、密度和与灯光的关系。

### 动线

- 必须能说清楚进场、停留、绕行、离场四步。
- 优先让人自然走到主装置和拍照点，而不是硬拐弯。

### 拍照点

- 负责社媒传播和停留转化。
- 先判断是“正面打卡”“斜侧合影”还是“穿越式沉浸拍摄”。

## 空间 Prompt 固定骨架

```text
空间类型 + 活动主题 + 品牌气质 + 体块语言 + 主要材质 + 灯光策略 + 视线焦点 + 人群动作 + 摄影视角 + 输出风格
```

## 常见负面约束

- 比例失真、入口太窄、主装置像舞台而不是商业空间
- 只有发光线条，没有结构体块
- 地贴只是图案，没有导流逻辑
- 拍照点孤立存在，与主装置无关
- 画面很满，但没有可执行落位

# Compact Research Bank

用这份研究库做快速起步。它只保留官方来源链接、观察结论、prompt 转译规则和 failure risks，不保存任何原图，也不代表官方授权。

## Apple

品牌 / 产品线：Apple / iPhone

Sources：

- https://www.apple.com/newsroom/2024/09/apple-debuts-iphone-16-pro-and-iphone-16-pro-max/
- https://www.apple.com/iphone/
- https://support.apple.com/en-us/121031

观察结论：

- 官方公开页面长期维持“工业精密 + 纯净背景 + 高控制力产品光线”的视觉领地。
- 新闻稿和产品页都强调边界更薄、显示更大、镜头能力更强，说明 hero 画面通常把轮廓、边缘与材质打磨放在前面。
- 页面气质不是奢侈堆料，而是把硬件做成冷静、明确、可信的产品对象。

Prompt translation rules：

- 用近中景 hero、受控边缘高光、极简背景、克制反射和清晰材质层次。
- 场景适合：纯净棚拍、轻建筑感空间、深灰或钛金属语境，不宜做成繁杂生活方式拼贴。
- 文字策略：留白给后期，不要求模型生成苹果式标题和技术文案。

Failure risks：

- 假 logo、过度未来感 UI、无意义霓虹、廉价 3D 渲染感。
- 把“精密”误做成“花哨科技”。
- 用太多道具导致主体不再像 Apple 公共页面中的单点聚焦。

## Nike

品牌 / 产品线：Nike / Air Max Dn8

Sources：

- https://about.nike.com/en/newsroom/releases/nike-air-max-dn8-official-images
- https://www.nike.com/t/air-max-dn8-mens-shoes-YPsmAOxu
- https://www.nike.com/w/air-max-dn8-shoes-5ju6gzy7ok

观察结论：

- 公开页面把 Dn8 定位为 Dynamic Air 的“下一章”，强调脚下空气感、速度感和文化能量，而不是传统性能说明书。
- 产品页与新闻页都把鞋当作轮廓鲜明、底部科技感强、颜色敢用的动作对象。
- 视觉世界偏“运动雕塑 + 城市能量”，而不是高端时装静物。

Prompt translation rules：

- 用低机位、侧前角度、切边构图、可见鞋底结构、强节奏阴影和地面纹理。
- 材质重点放在网布、橡胶、发泡和空气单元的层次，而不是夸张火焰或爆炸。
- 适合：城市地面、跑动前后瞬间、动势清晰的产品 hero。

Failure risks：

- 俗套火焰、过量粒子、廉价赛博霓虹。
- 把鞋做成奢侈品棚拍，失去运动能量。
- 随机品牌字、失真鞋底、双鞋反射错乱。

## Porsche

品牌 / 产品线：Porsche / 911

Sources：

- https://newsroom.porsche.com/en/products/911.html
- https://newsroom.porsche.com/en_US/model-range/911/911-carrera.html
- https://newsroom.porsche.com/en_US.html

观察结论：

- 官方公开页面长期强调 911 的轮廓、路感、机械欲望和可识别的车身曲线。
- 媒体页把产品信息与影像素材并置，说明该品牌官方愿意被看见的是“性能 + 轮廓 + 驾驶情绪”的组合。
- 这类视觉领地比一般豪华汽车更依赖道路接触、车身姿态和黄昏/夜色下的表面张力。

Prompt translation rules：

- 用低机位、长侧轮廓、车身曲线高光、沥青纹理、暖冷对比的道路环境。
- 场景更适合山路、城市夜归、车库出入口、路面反光，而不是玻璃办公楼科幻展厅。
- 重点控制车轮接地、车身比例、反射逻辑与车灯识别，而不是硬造 badge。

Failure risks：

- 假 badge、漂浮轮胎、过度 motion blur、廉价超跑 cliché。
- 把 Porsche 做成 generic red sports car。
- 把公开页面里的雕塑感做成过度未来化的概念车。

## Dyson

品牌 / 产品线：Dyson / Airwrap i.d.

Sources：

- https://www.dyson.com/discover/news/latest/introducing-dyson-airwrap-id-multi-styler-and-dryer
- https://www.dyson.com/hair-care/hair-stylers/airwrap-id/straight-wavy-amber-silk
- https://www.dyson.com/support/hair-care/hair-stylers/airwrap-id

观察结论：

- 公开页面强调“连接性 + 自动化 + 工程感美容器具”，视觉上既有人物使用场景，也保留器械结构展示。
- 产品页反复出现气流路径、附件逻辑、柔和但精确的高光与清洁背景，说明它不是传统彩妆式 glamour，而是工程产品的美妆版本。
- 颜色与材质倾向克制但不冷漠，强调塑料、金属、气流图示与头发成形结果。

Prompt translation rules：

- 用整洁背景、近中景产品与手部动作、柔和高光、局部示意式气流路径或动态线索。
- 如果要拍人物，重点是使用中的手势、头发质感和器具结构，而不是大情绪时尚大片。
- 版式留白适合做参数说明或卖点标题，但文字仍建议后期添加。

Failure risks：

- 美发工具被做成廉价电商白底或反过来做成浮夸彩妆广告。
- 手部结构错误、发丝塑料感、器具比例不准。
- 过量科技 HUD 导致视觉跑偏。

## Aesop

品牌 / 产品线：Aesop / Fragrance and store experience

Sources：

- https://www.aesop.com/our-story.html
- https://www.aesop.com/philosophy-on-design.html
- https://www.aesop.com/fragrance/fresh/tacit-eau-de-parfum/FR12.html
- https://shop.aesop.com/fr/en/r/store-experience/

观察结论：

- 官方页面强调配方、气味、设计哲学和空间体验，视觉领地是“克制、触感、建筑感、温和知识性”。
- Tacit 产品页把香气描述成地理与植物启发，适合把产品做成具有环境记忆的对象，而不是珠光宝气的奢侈品。
- 店铺体验与设计哲学页说明 Aesop 的公共形象高度依赖材质、容器、建筑表面和安静的秩序。

Prompt translation rules：

- 用石材、木材、纸、玻璃、陶土、柔和自然光和低饱和背景，强调触感与容器比例。
- 场景适合：安静洗手池、阅读桌面、建筑角落、浴室石面、微距瓶身与手部关系。
- 文字策略：留出空白标签区，不要求模型复刻 Aesop 标签排版。

Failure risks：

- 廉价黑金 luxury、过度 glossy、过饱和植物背景。
- 把 Aesop 做成时尚香水硬广，失去建筑感与克制。
- 直接模仿标签正面、店铺布局或品牌字体。

# 示例

## 示例 1：阅读品牌 3 方向

```text
输入理解：
- 品牌定位：年轻人的阅读陪伴工具。
- 目标用户：想读书但需要轻陪伴的人。
- 禁区：不要学术机构感、不要鸡汤海报、不要最终 logo 承诺。

方向 1：窗光纸张
- 核心气质：温柔、可信、慢下来。
- 视觉系统：自然窗光、纸张纹理、低饱和米白与浅绿、近景手部与书页。
- Prompt：生成一张品牌方向稿：自然窗光落在展开的书页和便签上，旁边有一杯温水和柔和植物影子，画面低饱和、安静、可信，留出干净文字区，不生成可读文字或 logo。
- 风险：可能过于普通，需要强化品牌符号母题。
- 下一轮问题：是否需要加入人物关系？
```

## 示例 2：护肤品牌方向审查

```text
方向审查：
- 最强方向：透明实验室，因为能连接科学与干净感。
- 最弱方向：水滴特写，因为太容易廉价和 generic。
- 品牌偏移：过度白蓝会像医院。
- 下一轮问题：更想强调敏感肌安全，还是日常愉悦？
```

## 示例 3：SVG 草图安全处理

```text
Logo/符号探索说明：
- 这不是最终 logo：当前 SVG 只能作为符号母题线索。
- 可探索的视觉母题：开口圆、入口、陪伴环、阅读页翻开。
- 生图 prompt：生成一张品牌方向稿，画面中有抽象开口圆形光影作为品牌符号占位，与纸张、阅读桌面和柔和自然光结合，不生成可读文字，不复制现有 logo。
- 后续专业设计动作：矢量网格、小尺寸识别、黑白版、字体匹配、商标检索。
```
